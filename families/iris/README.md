# iRiS

One living body for the whole desktop: the Island, the chassis around your screen and a Dock that grows out of it,
all moving on the same springs. Themes set material, shape, type and motion together.

| What | Where |
| --- | --- |
| Island, Dock, Surround | the edges of every screen |
| Settings | Super+, |
| Switching family | Settings, or `inir panelFamily set iris` |

Made by Hikari and snowarch.
