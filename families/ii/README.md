# Material

The family most people run: Material 3 Expressive panels, bars, docks and widgets, in nine global styles
(Flow, Expressive, Glass and friends). Your wallpaper picks the colours, you pick the shape.

| What | Where |
| --- | --- |
| Bar, dock, sidebars, control panel, overview | everywhere, each one movable and optional |
| Settings | Super+, |
| Switching family | Settings, or `inir panelFamily set ii` |
