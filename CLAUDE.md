## In Claude Code

- The skill `hub-item` (`.claude/skills/hub-item/SKILL.md`) is the whole path for a new item or a change to one, from
  the template to the pull request. Use it for any item work.
- The rules in `.claude/rules/hub-*.md` load by themselves when you open the files they cover; read `hub-items.md`
  first anyway.
- Run `inir hub check` yourself after each round of edits and fix what it prints before showing the person anything.
